# 🤖 Groq AI Chatbot

A simple AI chatbot built using Groq API, Python, Flask, HTML, CSS, and JavaScript.

## ✨ Features

- 💬 AI conversations
- ⚡ Fast AI responses
- 🌐 Web-based chatbot
- 📱 Responsive design
- 🔐 Secure API key using `.env`

## 🛠️ Technologies Used

- Python
- Groq API
- Flask
- HTML
- CSS
- JavaScript

## 🚀 How to Run

1. Install the required packages:

```bash
pip install groq flask python-dotenv
```

2. Create a `.env` file and add your Groq API key:

```text
GROQ_API_KEY=your_groq_api_key_here
```

3. Run the chatbot:

```bash
python app.py
```

4. Open this in your browser:

```text
http://127.0.0.1:5000
```

## 🔐 Security

The `.env` file is added to `.gitignore` so the API key is not uploaded to GitHub.
